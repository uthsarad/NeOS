## Accessibility fixes
- Added `.setAccessibleName()` and `.setAccessibleDescription()` to all primary and secondary action buttons to provide explicit screen reader context.

## UX improvements
- Added `.setWordWrap(True)` to the application title, subtitle, and version labels to prevent UI text clipping under various screen sizes.

## Remaining usability risks
- The application currently lacks dark mode/light mode toggle support which may limit accessibility for users preferring a light theme.
